## 📚 Comprehensive Final Exam Coverage
The final exam is cumulative, covering foundational equation-solving techniques through advanced polynomial and rational behavior. The curriculum is structured across four core competency modules:

### **Module 1: Foundations, Equations, & Inequalities (Exam 1 Review)**
*   **Linear & Rational Equations:** Solving standard linear equations and clearing denominators in rational equations ($\text{Section } 1.1$).
*   **Complex Numbers:** Operations with imaginary units ($i$), powers of $i$, and complex arithmetic ($\text{Section } 1.3$).
*   **Quadratic Equations:** Solving via factoring, square root property, completing the square, and the quadratic formula ($\text{Section } 1.4$).
*   **Advanced Equations & Applications:** Radical equations, power equations, quadratic-form equations, and word problems ($\text{Section } 1.6$).
*   **Inequalities:** Solving linear, compound, and absolute value inequalities with interval notation ($\text{Section } 1.7$).

### **Module 2: Coordinate Geometry & Linear Functions (Exam 2 Review)**
*   **Rectangular Coordinate System:** Distance formula, midpoint formula, and coordinate plane fundamentals ($\text{Section } 2.1$).
*   **Circles:** Standard form equation of a circle, finding centers/radii, and completing the square ($\text{Section } 2.2$).
*   **Functions & Relations:** Domain, range, function notation, and the Vertical Line Test ($\text{Section } 2.3$).
*   **Linear Functions:** Slopes, intercepts, and writing slope-intercept equations ($\text{Section } 2.4$).
*   **Linear Modeling:** Setting up and solving real-world applications using linear models ($\text{Section } 2.5$).

### **Module 3: Advanced Functions, Polynomials, & Rational Analysis (Exam 3 Review)**
*   **Graph Analysis & Piecewise Functions:** Evaluating graphs, determining symmetry (even/odd), and evaluating piecewise-defined functions ($\text{Section } 2.7$).
*   **Function Operations & Composition:** Arithmetic combinations of functions and composite functions $(f \circ g)(x)$ ($\text{Section } 2.8$).
*   **Graph Transformations:** Shifting, stretching, compressing, and reflecting parent functions ($\text{Section } 2.6$).
*   **Quadratic Applications:** Finding vertices, minimum/maximum values, and modeling real-world parabolas ($\text{Section } 3.1$).
*   **Polynomial Functions:** Recognizing polynomial behavior, end behavior, and turning points ($\text{Section } 3.2$).
*   **Polynomial Division:** Long and synthetic division, plus the Remainder and Factor Theorems ($\text{Section } 3.3$).
*   **Zeros of Polynomials:** Finding real zeros, multiplicity, and applying the Rational Zero Theorem ($\text{Section } 3.4$).
*   **Rational Functions:** Introduction to rational expressions and asymptotic analysis ($\text{Section } 3.5$).

### **Module 4: Inverse Functions & Final Integration**
*   **Inverse Functions:** Verifying inverse functions algebraically and finding $f^{-1}(x)$ for linear and rational functions ($\text{Section } 4.1$).
